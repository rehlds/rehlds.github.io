# Créditos

O ReUnion é a continuação do projeto DProto, adaptada para o ReHLDS e mantida pela comunidade do ReHLDS.

- [@Crock](https://github.com/theCrock), [@Lev](https://github.com/LevShisterov) e os demais que participaram ou ajudaram a desenvolver o [DProto](https://cs.rin.ru/forum/viewtopic.php?f=29&t=55986) original.
- [@Asmodai](https://github.com/theAsmodai) — ex-mantenedor do projeto ReUnion.
- [@dreamstalker](https://github.com/dreamstalker) — o projeto ReHLDS e os colaboradores envolvidos neste projeto.
- [@NordicWarrior](https://github.com/Nord1cWarr1or) — testes e retorno.
- [@kazakh758](https://github.com/kazakh758) — testes de uma correção para o problema de travamento do cliente na conexão.

## Como ajudar

Rode o ReUnion no seu servidor de jogo e relate os problemas pelo [rastreador de issues](https://github.com/rehlds/ReUnion/issues), informando a sua versão do ReHLDS, o `reunion.cfg` e a saída de console obtida com `-console +log on +mp_logecho 1`. Pull requests também são bem-vindos.
