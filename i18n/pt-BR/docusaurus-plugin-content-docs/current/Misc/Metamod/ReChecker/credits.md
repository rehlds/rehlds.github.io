# Créditos

O ReChecker é um plugin do Metamod escrito originalmente por s1lentq e mantido desde então pela comunidade do ReHLDS.

## Links do projeto

- [Repositório do código-fonte](https://github.com/rehlds/ReChecker)
- [Lançamentos](https://github.com/rehlds/ReChecker/releases)
- [Rastreador de issues](https://github.com/rehlds/ReChecker/issues)
- [Changelog](https://github.com/rehlds/ReChecker/blob/master/CHANGELOG.md)
- [Organização ReHLDS](https://github.com/rehlds)

## Como ajudar

Rode o ReChecker no seu servidor de jogo e relate os problemas pelo [rastreador de issues](https://github.com/rehlds/ReChecker/issues), informando as suas versões de ReHLDS e Metamod e a parte relevante do seu `resources.ini`. Pull requests também são bem-vindos.
