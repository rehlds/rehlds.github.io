# Projeto e licença

O ReGameDLL_CS é mantido pela comunidade do ReHLDS. Ele reconstrói e amplia a GameDLL do lado do servidor do Counter-Strike/Condition Zero, para que operadores de servidor e desenvolvedores de plugins tenham uma implementação mantida e auditável.

## Links do projeto

- [Repositório do código-fonte](https://github.com/rehlds/ReGameDLL_CS)
- [Versão estável mais recente](https://github.com/rehlds/ReGameDLL_CS/releases/latest)
- [Rastreador de issues](https://github.com/rehlds/ReGameDLL_CS/issues)
- [Organização ReHLDS](https://github.com/rehlds)

## Licença

A árvore de código atual é distribuída sob a licença incluída no repositório oficial. O ReGameDLL_CS migrou para a licença MIT em 2025; consulte o arquivo [`LICENSE`](https://github.com/rehlds/ReGameDLL_CS/blob/master/LICENSE) atual do repositório para conhecer os termos definitivos antes de redistribuir o código ou os binários.

Valve, Counter-Strike, Half-Life e os nomes e materiais relacionados pertencem aos seus respectivos donos. O ReGameDLL_CS não inclui todos os dados comerciais do jogo necessários para rodar um servidor.
