# Créditos

O ReAPI é um módulo do AMX Mod X mantido pela comunidade do ReHLDS. Ele expõe as entranhas do [ReHLDS](/pt-BR/docs/rehlds) e do [ReGameDLL_CS](/pt-BR/docs/regamedll-cs) aos plugins em Pawn por meio de cadeias de hooks, acessores de membros e natives de verificação de capacidade, para que os autores de plugins não precisem aplicar patches em offsets de memória por conta própria.

## Como ajudar

Rode o ReAPI no seu servidor de jogo e relate os problemas que encontrar pelo [rastreador de issues](https://github.com/rehlds/ReAPI/issues), informando as suas versões de AMX Mod X, ReHLDS e ReGameDLL_CS, a lista de plugins e os passos para reproduzir. Pull requests também são bem-vindos.
