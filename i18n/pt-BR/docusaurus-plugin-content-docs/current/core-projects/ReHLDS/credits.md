# Créditos

O ReHLDS é fruto da engenharia reversa do HLDS original (build 6152/6153), feita a partir das informações de depuração DWARF embutidas na build Linux do HLDS (`engine_i486.so`). Ao longo do caminho, os mantenedores e colaboradores do projeto encontraram e corrigiram um grande número de defeitos e possíveis bugs do motor original. Ele é mantido pela comunidade do ReHLDS como um projeto de código aberto e sem fins comerciais.

Veja o [LICENSE-TRANSITION.md](https://github.com/rehlds/ReHLDS/blob/master/LICENSE-TRANSITION.md) para o aviso completo.

Valve, Half-Life, Counter-Strike e os nomes e materiais relacionados pertencem aos seus respectivos donos. O ReHLDS não inclui os dados comerciais do jogo necessários para rodar um servidor — você ainda precisa de uma cópia legítima do HLDS e do mod correspondente.

## Como ajudar

Rode o ReHLDS no seu servidor de jogo e relate os problemas que encontrar pelo [rastreador de issues](https://github.com/rehlds/ReHLDS/issues) — veja a [Solução de problemas](./troubleshuting.md) para saber o que incluir em um relato. Pull requests também são bem-vindos.
