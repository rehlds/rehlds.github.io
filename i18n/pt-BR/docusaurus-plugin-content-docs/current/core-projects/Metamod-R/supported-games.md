# Jogos compatíveis

Entusiastas da comunidade analisaram as versões conhecidas do _Metamod_,

* [metamod (Original)](https://sourceforge.net/projects/metamod/files/Metamod%20Sourcecode/1.20/) ("games.h"), 
* [metamod-p](https://github.com/jkivilin/metamod-p/blob/master/metamod/games.h), 
* [metamod-p-cmake](https://github.com/SamVanheer/Metamod-P-CMake/blob/master/metamod/games.h) (apenas um fork, otimizado para a compilação com CMake)
* [metamod-am\metamod-hl1](https://github.com/alliedmodders/metamod-hl1/blob/master/metamod/games.h) from [alliedmodders](https://github.com/alliedmodders/).
montaram uma lista clara e atual de mods, verificaram (**`de forma resumida*`**) o funcionamento deles e adicionaram suporte "de fábrica" a esses jogos no **[Metamod-r](https://github.com/rehlds/metamod-r)**.

## Problemas conhecidos

### SvenCoop

#### "Precache limit - 512"
![image](https://user-images.githubusercontent.com/34998786/37242681-89c5da6a-24a8-11e8-8ef2-97188b70a6f3.png)

O jogo tem um limite modificado para o pré-carregamento de objetos no motor e no cliente. Como o metamod-r exige o rehlds, o limite do lado do servidor volta ao padrão de 512 objetos. Em consequência, o mod não roda em mapas que ultrapassam esse limite (o modo cooperativo em mapas de campanha). Ao mesmo tempo, os mapas multijogador padrão, como o `crossfire`, funcionam normalmente. (_Não é um bug do [metamod-r #29](https://github.com/rehlds/metamod-r/issues/29) nem do [rehlds #591](https://github.com/rehlds/ReHLDS/issues/591), mas afeta os dois_). 

##### Como corrigir:
* Tente atualizar a versão da `steam` do svencoop para a [Build 3082297](https://forums.svencoop.com/showthread.php/45308-Sven-Co-op-Update-Released-Build-3082297).

> A compatibilidade de API/ABI com o GoldSrc/Metamod-P originais foi restaurada. A build própria do Metamod-P para o Sven Co-op não é mais necessária (e, na prática, não vai mais funcionar).

##### Soluções alternativas:
* Tente usar o ![](https://i.imgur.com/AzhAYR4.png) [metamod_unprecacher](https://github.com/In-line/metamod_unprecacher) ou algo parecido para bloquear recursos não utilizados.  `não testado`
* Tente compilar uma build própria do rehlds com o limite ampliado que o svencoop usa.  `não testado`
