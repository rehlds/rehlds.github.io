# Créditos

O **Metamod-r** é baseado na versão original do [Metamod](http://metamod.org/), escrita por _Will Day_ para o Half-Life 1, com algumas melhorias de [Jussi Kivilinna](https://github.com/jkivilin) ([Metamod-p](https://github.com/jkivilin/metamod-p)). Este produto traz um grande número de otimizações de desempenho e um código mais limpo. O núcleo foi escrito com um compilador JIT.

**O Metamod-r é incompatível com o `HLDS` original. É necessário ter o [ReHLDS](https://github.com/rehlds/ReHLDS) instalado (`API 3.1+`). Não há garantia de que o produto funcione em um ambiente diferente.**

Distribuído sob a [![GitHub license](https://img.shields.io/github/license/rehlds/metamod-r.svg?style=flat-square)](https://github.com/rehlds/metamod-r/blob/master/LICENSE).
