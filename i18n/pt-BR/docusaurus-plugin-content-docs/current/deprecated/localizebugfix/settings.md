# Configurações

:::warning Descontinuado

Mantido como referência. O projeto está arquivado — leia [O que é o LocalizeBug Fix?](./index.md).

:::

O LocalizeBug Fix **não tinha configuração**. Ele não registrava cvars nem comandos de console, e não distribuía nenhum arquivo de configuração. Carregar o plugin já ativava a proteção; não havia nada a ajustar.

Essa é uma diferença real em relação ao substituto moderno: o [SafeNameAndChat](/pt-BR/docs/safenameandchat/settings) expõe onze cvars, para que você escolha quais caracteres são higienizados nos nomes e no bate-papo. O LocalizeBug Fix era tudo ou nada.

:::note

Se você chegou a esta página esperando suavizar o comportamento do plugin porque ele atrapalha alguma coisa, não existe configuração para isso — as únicas opções são carregá-lo ou não. Em um servidor atual, use o [SafeNameAndChat](/pt-BR/docs/safenameandchat), no qual as proteções individuais podem ser desativadas.

:::
