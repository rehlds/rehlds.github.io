# Настройки

:::warning Устаревший проект

Сохранено для справки. Плагин несовместим с современными версиями ReHLDS — см. [Что такое ReLocalizeBug Fix?](./index.md).

:::

У ReLocalizeBug Fix **не было конфигурации**. Как и [LocalizeBug Fix](/ru/docs/localizebugfix/settings), на основе которого он сделан, плагин не регистрировал ни консольных переменных, ни команд и не поставлял файла настроек. Загрузка плагина включала защиту; настраивать было нечего.

Его современная замена, [SafeNameAndChat](/ru/docs/safenameandchat/settings), предоставляет одиннадцать переменных, раздельно охватывающих ники и чат, так что отдельные защиты можно отключить, если они с чем-то конфликтуют.

:::note

Поскольку настроек не было, нет и способа заставить этот плагин нормально работать на неподдерживаемой сборке ReHLDS. Если он сбоит, решение — удалить его, а не искать обходную конфигурацию.

:::
