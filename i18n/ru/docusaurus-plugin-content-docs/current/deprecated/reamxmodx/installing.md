# Установка

:::warning Устаревший проект

Не устанавливайте ReAMXModX на современный сервер. Ставьте [AMX Mod X](https://www.amxmodx.org/) от AlliedModders: он поддерживает ReHLDS сам по себе, а это единственное, ради чего существовал данный форк.

:::

## Устанавливать нечего

ReAMXModX **не публиковал выпусков**. В репозитории только исходный код — ни страницы выпусков, ни архивов, ни готовых сборок. Всякому, кто хотел его запустить, приходилось сначала [собрать проект из исходного кода](./compilling.md).

Уже этого достаточно, чтобы считать его непригодным для обычной установки сегодня: вам пришлось бы самостоятельно собирать срез AMX Mod X 2016 года, а затем в одиночку его сопровождать.

## Если вы с него уходите

Если вам достался сервер со сборкой этого форка, штатный путь — переход на основной AMX Mod X:

1. Установите актуальный выпуск [AMX Mod X](https://www.amxmodx.org/downloads-new.php) для вашего мода, следуя его собственной документации.
2. Сохраните существующий каталог `configs/` — формат конфигурации форк не менял, поэтому `amxx.cfg`, `users.ini`, `cmds.ini` и остальные переносятся без изменений. См. [Настройки](./settings.md).
3. Перекомпилируйте собственные плагины `.sma` с актуальными заголовочными файлами AMX Mod X.
4. Проверьте результат командами `amxx version` и `amxx modules` в консоли сервера.

Для доступа к движку и GameDLL из Pawn на современной связке используйте [ReAPI](/ru/docs/reapi), а не пропатченный AMX Mod X, — сегодня это и есть поддерживаемый способ добраться до внутреннего устройства ReHLDS и ReGameDLL_CS.
