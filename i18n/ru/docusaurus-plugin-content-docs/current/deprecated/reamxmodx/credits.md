# Авторы

ReAMXModX — форк **AMX Mod X**, созданного и поддерживаемого [AlliedModders](https://www.amxmodx.org/). Вся содержательная работа в этом репозитории принадлежит им; форк добавляет поверх среза ветки разработки `1.8.3` (`git5067`) от августа 2016 года прослойку SDK для ReHLDS и ReGameDLL.

Абстрактная машина и компилятор Pawn, поставляемые вместе с AMX Mod X, — © ITB CompuPhase, 1997–2005.

:::warning Устаревший проект

Форк **устарел** — основной AMX Mod X поддерживает ReHLDS сам по себе. Используйте [AMX Mod X](https://www.amxmodx.org/).

:::

## Лицензия

Лицензирование следует основному AMX Mod X. Тексты лицензий лежат в репозитории в каталоге `public/licenses/` — файл `LICENSE.txt` вместе с копиями GPL v2 и v3, а также `ACKNOWLEDGEMENTS.txt` для входящего в состав компилятора Pawn. Сверяйтесь с этими файлами и с основным AMX Mod X, прежде чем распространять что-либо собранное из этого дерева.

Valve, Half-Life, Counter-Strike и связанные названия и ресурсы принадлежат их владельцам.

## Как помочь проекту

Этот форк новую работу не принимает. Участвуйте в [основном AMX Mod X](https://github.com/alliedmodders/amxmodx) или — для доступа к внутреннему устройству ReHLDS и ReGameDLL_CS из Pawn на современном сервере — в [ReAPI](/ru/docs/reapi).
