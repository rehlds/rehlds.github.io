# Настройки

:::warning Устаревший проект

Сохранено для справки. Используйте [AMX Mod X](https://www.amxmodx.org/) от AlliedModders — см. [Что такое ReAMXModX?](./index.md).

:::

ReAMXModX **не вводил собственной конфигурации**. Его изменения были внутренней прослойкой SDK для API ReHLDS и ReGameDLL, а не пользовательскими возможностями, поэтому вся область настроек принадлежит основному AMX Mod X.

Форк содержит стандартный набор конфигураций AMX Mod X в каталоге `configs/`:

| Файл | Назначение |
| --- | --- |
| `amxx.cfg` | Основная конфигурация AMX Mod X и его переменные. |
| `core.ini` | Настройки модуля ядра. |
| `configs.ini` | Выбор конфигураций для конкретного мода. |
| `modules.ini` | Какие модули загружать при запуске. |
| `plugins.ini` | Какие плагины загружать при запуске. |
| `users.ini` | Учётные записи администраторов и флаги доступа. |
| `cmds.ini`, `clcmds.ini` | Определения серверных и клиентских команд. |
| `cvars.ini` | Определения переменных, используемых в меню. |
| `maps.ini` | Список карт для меню выбора карты. |
| `hamdata.ini` | Смещения функций для Ham Sandwich. |
| `custommenuitems.cfg`, `miscstats.ini` | Пункты меню и отображение статистики. |

Все они ведут себя ровно так, как описано в документации AlliedModders, — форк не менял ни их форматов, ни значений по умолчанию.

:::note

Поскольку конфигурация идентична, сервер, переходящий с этого форка на актуальный основной AMX Mod X, может сохранить каталог `configs/` как есть. Одно исключение стоит проверить вручную: в `hamdata.ini` хранятся смещения функций, а они привязаны к версии AMX Mod X и к используемой GameDLL, — берите файл из актуального выпуска, а не переносите копию 2016 года.

:::

Первоисточник — [документация AMX Mod X](https://wiki.alliedmods.net/Category:AMX_Mod_X) и [справочник по командам AMX Mod X](https://wiki.alliedmods.net/Commands_(AMX_Mod_X)).
