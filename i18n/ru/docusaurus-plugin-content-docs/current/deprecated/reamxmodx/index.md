# Что такое ReAMXModX?

:::warning Устаревший проект

ReAMXModX **устарел**. В основном AMX Mod X с тех пор появилась собственная поддержка ReHLDS, что полностью лишило этот форк смысла существования.

Используйте [AMX Mod X](https://www.amxmodx.org/) от AlliedModders. Всё, что давал этот форк, сегодня есть в основном проекте — поддерживаемом и с выпусками.

:::

ReAMXModX — форк AMX Mod X, снятый в августе 2016 года с ветки разработки `1.8.3` (`git5067`). Его задачей было научить AMX Mod X работать с API ReHLDS и ReGameDLL в то время, когда основной проект о них ничего не знал.

## Что в нём изменено

Коммиты форка узкие и предметные. В ядро AMX Mod X и в несколько модулей добавлена прослойка SDK для интерфейсов ReHLDS и ReGameDLL — файлы `mod_rehlds_api.cpp` и `mod_gamedll_api.cpp` присутствуют в ядре, а также в модулях `cstrike`, `csx`, `engine` и `fakemeta`, — доведя в последнем коммите поддержку до ReHLDS API `3.x` и ReGameDLL API `5.x`.

Помимо этого форк содержит несколько исправлений:

- Утечка памяти в `unregister_forward`.
- Ошибка в чате, связанная с локализацией.
- Исправления выравнивания данных для сборок под Linux.

## Почему он устарел

В основном AMX Mod X появилась поддержка ReHLDS, и отдельный форк ради неё перестал быть нужен. Работа здесь прекратилась в декабре 2016 года, а выпусков проект не публиковал вовсе: устанавливать нечего, есть только исходный код, замороженный на девятилетнем срезе AMX Mod X.

Запустить его сегодня означало бы получить AMX Mod X образца 2016 года без всего, что вышло в основном проекте с тех пор, — в обмен на поддержку ReHLDS, которая в нём и так уже есть.

О том, как с ним работали, см. [Установка](./installing.md), [Настройки](./settings.md) и [Инструкция по сборке](./compilling.md).
