# Настройки

:::warning Устаревший проект

Сохранено для справки. hitboxtracker больше не поддерживается — см. [Что такое hitboxtracker?](./index.md).

:::

Собственных консольных переменных hitboxtracker не добавлял. Он расширял стандартную клиентскую переменную `r_drawentities` двумя дополнительными режимами, так что всё управление шло из консоли клиента.

## `r_drawentities`

| Значение | Назначение |
| --- | --- |
| `0` | Сущности не отрисовываются. |
| `1` | По умолчанию — обычная отрисовка сущностей. |
| `2` | Сущности отрисовываются скелетами. |
| `3` | Сущности отрисовываются хитбоксами. |
| `4` | Сущности отрисовываются полупрозрачными хитбоксами и моделью под ними. |
| `5` | Отдельная область для игрока и для оружия. |
| `6` | Добавлено hitboxtracker. То же, что `4`, плюс отрисовка истинного положения хитбоксов, рассчитанного сервером. |
| `7` | Добавлено hitboxtracker. То же, что `6`, но без полупрозрачности. |

Значения `0`–`5` принадлежат самому движку и работают без этого инструмента. Только `6` и `7` требовали, чтобы были установлены обе половины hitboxtracker.

:::note

Смысл режимов `6` и `7` был именно в *расхождении*: вы сравнивали собственные области клиента с серверными, и заметное смещение между ними объясняло жалобы на незасчитанные попадания, которые иначе выглядели как выдумки игрока.

:::
