# Авторы

hitboxtracker разрабатывался внутри организации ReHLDS как диагностический инструмент. Первый публичный выпуск `v1.0` состоялся в декабре 2017 года, за ним последовал `v1.1` в январе 2018 года, в котором передача данных о хитбоксах была переведена с delta на сообщение `svc_director`.

:::warning Устаревший проект

Проект **устарел и больше не поддерживается**. На современном сервере используйте [Hitbox Fixer](/ru/docs/hitbox-fixer).

:::
