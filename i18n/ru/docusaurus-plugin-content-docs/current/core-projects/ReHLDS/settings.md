# Настройки

ReHLDS добавляет набор серверных консольных переменных (CVar) к стандартным переменным HLDS — в основном для настройки защиты от читов и злоупотреблений, работы с сетью и исправлений поведения движка. Задавайте их в `server.cfg` или в любом конфигурационном файле, выполняемом при запуске.

## CVar

| CVar | По умолчанию | Назначение |
| --- | --- | --- |
| `sv_auto_precache_sounds_in_models` | `0` | Автоматически предзагружать звуки, привязанные к моделям. |
| `sv_delayed_spray_upload` | `0` | Передавать пользовательские логотипы после входа в игру, а не при подключении. Повышает скорость передачи. |
| `sv_echo_unknown_cmd` | `0` | Выводить в консоль сообщение, когда клиент пытается выполнить неизвестную команду. |
| `sv_rcon_condebug` | `1` | Выводить в консоль отладочную информацию RCON. |
| `sv_force_ent_intersection` | `0` | Используется сторонними плагинами для принудительного включения столкновений у сущностей `SOLID_SLIDEBOX`. |
| `sv_rehlds_force_dlmax` | `0` | Принудительно выставлять клиентскую переменную `cl_dlmax` в `1024`, избегая избыточной фрагментации пакетов. |
| `sv_rehlds_hull_centering` | `0` | Использовать центр хитбокса вместо его угла. |
| `sv_rehlds_movecmdrate_max_avg` | `400` | Максимальный средний уровень команд движения, допустимый до выдачи бана. |
| `sv_rehlds_movecmdrate_avg_punish` | `5` | Длительность бана в минутах за превышение `sv_rehlds_movecmdrate_max_avg` (`0` — навсегда, отрицательное значение — кик). |
| `sv_rehlds_movecmdrate_max_burst` | `2500` | Максимальный пиковый уровень команд движения, допустимый до выдачи бана. |
| `sv_rehlds_movecmdrate_burst_punish` | `5` | Длительность бана в минутах за превышение `sv_rehlds_movecmdrate_max_burst` (`0` — навсегда, отрицательное значение — кик). |
| `sv_rehlds_send_mapcycle` | `0` | Передавать `mapcycle.txt` в сообщении с информацией о сервере (соответствует поведению оригинального HLDS; клиентом не используется). |
| `sv_rehlds_stringcmdrate_max_avg` | `80` | Максимальный средний уровень строковых команд, допустимый до выдачи бана. |
| `sv_rehlds_stringcmdrate_avg_punish` | `5` | Длительность бана в минутах за превышение `sv_rehlds_stringcmdrate_max_avg` (`0` — навсегда, отрицательное значение — кик). |
| `sv_rehlds_stringcmdrate_max_burst` | `400` | Максимальный пиковый уровень строковых команд, допустимый до выдачи бана. |
| `sv_rehlds_stringcmdrate_burst_punish` | `5` | Длительность бана в минутах за превышение `sv_rehlds_stringcmdrate_max_burst` (`0` — навсегда, отрицательное значение — кик). |
| `sv_rehlds_userinfo_transmitted_fields` | `""` | Клиентам по сети передаются только перечисленные здесь ключи userinfo. Пустое значение означает передачу всех полей (кроме ключей с префиксом `_`). Каждый ключ указывайте с обратной косой чертой, например `\name\model\*sid\*hltv\bottomcolor\topcolor`. Полный справочник — [Userinfo keys](https://github.com/rehlds/ReHLDS/wiki/Userinfo-keys). |
| `sv_rehlds_attachedentities_playeranimationspeed_fix` | `0` | Исправляет ошибку скорости анимации ног, возникающую, когда к игроку привязаны сущности (aiments). При низком `cl_updaterate` может приводить к задержке анимации. |
| `sv_rehlds_maxclients_from_single_ip` | `5` | Ограничивает число одновременных подключений с одного IP-адреса (на уже подключившихся игроков не влияет). |
| `sv_rehlds_local_gametime` | `0` | Уменьшает ощущение «лагов» при длительной игре на одной карте. |
| `sv_rehlds_allow_large_sprays` | `1` | Разрешает пользовательские логотипы размером больше 64x64. |
| `sv_use_entity_file` | `0` | Управляет использованием отдельного файла сущностей для карты (`maps/[имя карты].ent`). `0` — исходные сущности, `1` — использовать файлы `.ent` из каталога карт, `2` — использовать файлы `.ent` и создавать их при отсутствии. |
| `sv_usercmd_custom_random_seed` | `0` | Заполнять дополнительное зерно случайных чисел независимо от клиента. |
| `sv_net_incoming_decompression` | `1` | Распаковывать входящие сжатые данные при передаче файлов. |
| `sv_net_incoming_decompression_max_ratio` | `80.0` | Максимально допустимое соотношение сжатых и несжатых данных при передаче файлов, `0`–`100`. Значение около 90 указывает на большой объём несжатых данных с низкой энтропией. |
| `sv_net_incoming_decompression_max_size` | `65536` | Максимально допустимый размер распакованных данных при передаче файлов, в байтах, `16`–`65536`. |
| `sv_net_incoming_decompression_min_failures` | `4` | Минимальное число неудачных распаковок, после которого соединение помечается как кандидат на наказание, `0`–`10`. |
| `sv_net_incoming_decompression_max_failures` | `10` | Максимальное число неудачных распаковок в пределах отслеживаемого окна, после которого применяются меры, `0`–`10`. |
| `sv_net_incoming_decompression_min_failuretime` | `0.1` | Окно времени в секундах, `0.1`–`10.0`, в пределах которого отслеживаются неудачные распаковки. |
| `sv_net_incoming_decompression_punish` | `-1` | Длительность бана в минутах за некорректные или аномальные фрагменты bzip2 (`0` — навсегда, отрицательное значение — кик). |
| `sv_tags` | `""` | Список «игровых тегов» сервера через запятую, используется для фильтрации в подборе игр и браузерах серверов. |
| `sv_filterban` | `1` | Режим фильтрации по IP. `-1` — безусловно отклонять всех игроков, `0` — не выполнять проверок, `1` — отключать игроков, попадающих под фильтр или запись бана. |
| `sv_rehlds_movecmd_max_ticks` | `24` | Максимальное число команд движения, которое сервер обрабатывает от одного игрока за один кадр (именно команд, не пакетов). |
| `sv_rehlds_movecmd_max_null_streak` | `0` | Максимально допустимое число идущих подряд команд движения с нулевой длительностью (пустых команд). `0` отключает проверку. |
| `sv_rehlds_movecmd_clamp_interp` | `1` | Блокировать команды движения со значением `ex_interp` вне допустимого диапазона. |
| `sv_rehlds_movecmdtime_samples` | `120` | Число кадров, по которым усредняется скорость движения клиента. Больше — точнее, но обнаружение происходит медленнее. |
| `sv_rehlds_movecmdtime_max_error` | `300` | Насколько (в миллисекундах) внутренние игровые часы клиента могут расходиться с часами сервера, прежде чем будет оценена скорость. Наказание применяется только при одновременном нарушении `sv_rehlds_movecmdtime_max_scale` / `_min_scale`. |
| `sv_rehlds_movecmdtime_max_scale` | `3.0` | Максимальный коэффициент базовой игровой скорости клиента. Клиенты, ускоряющиеся сверх него, получают предупреждения. |
| `sv_rehlds_movecmdtime_min_scale` | `0.5` | Минимальный коэффициент базовой игровой скорости клиента. Клиенты, замедляющиеся ниже него, получают предупреждения. |
| `sv_rehlds_movecmdtime_max_warnings` | `-1` | Максимальное число предупреждений о спидхаке или замедлении до применения наказания. `-1` отключает обнаружение. |
| `sv_rehlds_movecmdtime_punish` | `-1` | Наказание за спидхак или замедление (`-1` — кик, `0` — бан навсегда, отрицательное значение — кик). |
| `sv_reconnect_timeout` | `30` | Жёсткий предел в секундах, за который клиент обязан заново установить соединение после смены карты, независимо от активности сетевого канала. Закрывает уязвимость с «фантомными» слотами, когда чит блокирует команду `reconnect`, поддерживая сетевой канал живым, так что `sv_timeout` не срабатывает. `0` отключает проверку. |

:::note

`sv_rehlds_userinfo_transmitted_fields` — настройка, которую чаще всего применяют вместе с конфигурациями для приватности и защиты от читов. Тип значения, передачу по умолчанию и замечания о приватности для каждого стандартного ключа смотрите на [вики-странице Userinfo keys](https://github.com/rehlds/ReHLDS/wiki/Userinfo-keys).

:::

## Файлы

| CVar | По умолчанию | Назначение |
| --- | --- | --- |
| `listipcfgfile` | `listip.cfg` | Файл, используемый для постоянных банов по IP. |
| `syserror_logfile` | `sys_error.log` | Файл журнала системных ошибок. |

## Консольные команды

| Команда | Назначение |
| --- | --- |
| `rescount` | Выводит в консоль сервера общее число предзагруженных ресурсов. |
| `reslist <sound \| model \| decal \| generic \| event>` | Выводит предзагруженные ресурсы указанного типа. Полезно для управления ресурсами и контроля лимитов предзагрузки GoldSrc. |
| `rcon_adduser <ipaddress/CIDR>` | Добавляет IP-адрес или диапазон CIDR в список пользователей RCON, предоставляя привилегированный доступ к консоли. Пока список пуст, RCON доступен любому, кто знает верный пароль. |
| `rcon_deluser <ipaddress> {removeAll}` | Удаляет IP-адрес или диапазон CIDR из списка пользователей RCON. |
| `rcon_users` | Выводит все IP-адреса и диапазоны CIDR из списка пользователей RCON. |
