# Установка

ReHLDS — это прямая замена файла движка HLDS. Установка сводится к тому, чтобы скачать базовый сервер HLDS через Steam, а затем перезаписать файл движка сборкой ReHLDS.

## 1. Установите базовый сервер HLDS

ReHLDS требует **доюбилейной** сборки HLDS из Steam (версия движка 8684 или ниже). Скачайте её с помощью `steamcmd`:

```text
app_set_config 90 mod cstrike
app_update 90 -beta steam_legacy validate
```

Если вы запускаете не Counter-Strike 1.6, замените `mod cstrike` на нужный вам мод.

:::warning

ReHLDS несовместим со старыми сборками 5xxx и ниже, установленными через устаревший `hldsupdatetool`. Всегда устанавливайте сервер через `steamcmd`, как показано выше.

:::

## 2. Скачайте ReHLDS

Возьмите сборку из одного из источников:

- [Стабильные выпуски](https://github.com/rehlds/ReHLDS/releases) — рекомендуются для боевых серверов.
- [Сборки для разработки](https://github.com/rehlds/ReHLDS/actions/workflows/build.yml) — свежие артефакты CI, полезны для проверки готовящихся исправлений.

Выберите архив, соответствующий платформе вашего сервера (Windows или 32-разрядный Linux).

## 3. Замените файл движка

1. Полностью остановите сервер.
2. Сделайте резервную копию текущего файла движка.
3. Скопируйте файл ReHLDS поверх оригинального:

| Платформа | Что заменять | Отладочные символы (необязательно) |
| --- | --- | --- |
| Windows | `swds.dll` | `swds.pdb` |
| Linux | `engine_i486.so` | — |

В архиве для Windows также поставляются `hlds.exe` / `hltv.exe` и библиотеки компонента ReHLTV (`core.dll`, `proxy.dll`, `demoplayer.dll`, `director.dll`, `filesystem_stdio.dll`); скопируйте вместе с `swds.dll` те из них, которые используются в вашей конфигурации.

4. В Linux убедитесь, что у заменённого файла сохранились прежние права доступа (чтение и выполнение для учётной записи, от которой работает сервер).
5. Запустите сервер. ReHLDS сообщает о себе в консоли при старте, поэтому убедиться в успешной замене можно по журналу.

## Проверка подписи выпуска (необязательно, но рекомендуется)

Архивы выпусков для Linux подписаны GPG. Отпечаток открытого ключа:

```text
63547829004f07716f7be4856c32c4282e60fb67
```

1. Скачайте ключ с сервера ключей, например с [keyserver.ubuntu.com](https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x63547829004f07716f7be4856c32c4282e60fb67).
2. Импортируйте его:

```bash
gpg --import 63547829004f07716f7be4856c32c4282e60fb67.asc
```

3. Скачайте как сам архив выпуска, так и приложенный к нему файл подписи `.asc`.
4. Выполните проверку:

```bash
gpg --verify some-rehlds.zip.asc some-rehlds.zip
```

## Замечания о совместимости

- ReHLDS **не является бинарно совместимым** с оригинальным HLDS (он собирается другими компиляторами). Плагины, выполняющие низкоуровневое патчинг движка или поиск по сигнатурам — известный пример Orpheu, — могут не работать, если в них нет явной поддержки ReHLDS.
- Если вы планируете использовать Metamod-R, ReAPI или ReGameDLL_CS, сначала установите ReHLDS — эти проекты рассчитывают, что он уже установлен. См. [установку Metamod-R](/ru/docs/metamod-r/install) и [установку ReGameDLL_CS](/ru/docs/regamedll-cs/install).
