# Настройки и команды

ReGameDLL_CS добавляет собственные настройки к стандартным серверным CVar Counter-Strike. Используйте файлы конфигурации из того же выпуска, что и GameDLL.

## Файлы конфигурации

| Файл | Назначение |
| --- | --- |
| `<mod>/game.cfg` | Игровые правила ReGameDLL_CS, HUD, движение, возрождение, урон и расширения квоты ботов. |
| `<mod>/game_init.cfg` | Параметры, необходимые при инициализации GameDLL: `bot_enable`, `hostage_ai_enable` и `mp_hullbounds_sets`. |
| `<mod>/server.cfg` | Обычные настройки сервера: имя, пароли, журналирование и стандартные CVar Counter-Strike. |

`<mod>` означает `cstrike` для CS 1.6 или `czero` для Condition Zero.

:::important

После изменения `game_init.cfg` полностью перезапустите процесс сервера. Одной смены карты может быть недостаточно для повторной инициализации встроенных ботов.

:::

## Основные настройки ReGameDLL_CS

Ниже приведены значения из текущей стабильной конфигурации. Сервер может их переопределить.

| CVar | Значение выпуска | Назначение |
| --- | ---: | --- |
| `mp_freeforall` | `0` | Включает режим «каждый сам за себя» при значении `1`. |
| `mp_round_infinite` | `0` | Не завершает раунд при выбранных условиях сценария. Принимает флаги, например `a`, `e` или `ae`. |
| `mp_round_restart_delay` | `5` | Задержка в секундах перед следующим раундом после победы. |
| `mp_roundrespawn_time` | `20` | Время после начала раунда, пока подключившийся игрок ещё может появиться; `-1` снимает ограничение. |
| `mp_forcerespawn` | `0` | Автоматически возрождает убитых игроков через указанную задержку. |
| `mp_maxmoney` | `16000` | Максимум денег игрока; ReGameDLL_CS допускает значения до `999999`. |
| `mp_buy_anywhere` | `0` | Покупки в любом месте: обе команды (`1`), только T (`2`) или только CT (`3`). |
| `mp_infinite_ammo` | `0` | `1` сохраняет полный магазин; `2` даёт бесконечный запас патронов. |
| `mp_infinite_grenades` | `0` | При `1` включает бесконечные гранаты. |
| `mp_free_armor` | `0` | Выдаёт бронежилет (`1`) или бронежилет со шлемом (`2`) при появлении. |
| `mp_team_flash` | `1` | Определяет, действует ли ослепление на союзников и бросившего гранату. |
| `sv_autobunnyhopping` | `0` | Автоматически прыгает, пока удерживается клавиша прыжка. |
| `sv_enablebunnyhopping` | `0` | Разрешает превышать обычное ограничение скорости бега. |
| `mp_scoreboard_showhealth` | `3` | Определяет, чьё здоровье передаётся и показывается в таблице счёта. |
| `mp_scoreboard_showmoney` | `3` | Определяет, чьи деньги передаются и показываются в таблице счёта. |
| `mp_allow_point_servercommand` | `0` | Разрешает картам выполнять серверные команды. Оставляйте выключенным для недоверенных карт. |

Полный список настроек, допустимых значений и предупреждений находится в исходном [`dist/game.cfg`](https://github.com/rehlds/ReGameDLL_CS/blob/master/dist/game.cfg).

## Серверные команды

Выполняйте их из консоли сервера или через авторизованный RCON, где это применимо.

| Команда | Описание |
| --- | --- |
| `game version` | Показывает версию, дату сборки и URL загруженной GameDLL. |
| `endround` | Завершает раунд ничьей. |
| `endround T` | Завершает раунд победой террористов. |
| `endround CT` | Завершает раунд победой контртеррористов. |
| `swapteams` | Меняет команды местами и перезапускает раунд через одну секунду. |
| `swapteams 0` | Меняет команды местами без перезапуска раунда. |
| `swapteams <seconds>` | Меняет команды и перезапускает раунд через указанное время. |
| `give weapon_ak47` | Выдаёт указанное оружие; требуется `sv_cheats 1`. |
| `impulse 255` | Выдаёт всё оружие; требуется `sv_cheats 1`. |
| `impulse 200` | Включает noclip с ускорением в воздухе; требуется `sv_cheats 1`. |

Команды ботов и примеры квот описаны в разделе [Использование ботов](../bots/).

## Безопасный порядок настройки

1. Храните копию неизменённой конфигурации каждого выпуска.
2. Меняйте по одной группе параметров за раз.
3. Перезапустите сервер или смените карту, затем проверьте действующее значение в консоли.
4. Храните собственные значения вне архива выпуска, чтобы обновление не перезаписало их незаметно.
