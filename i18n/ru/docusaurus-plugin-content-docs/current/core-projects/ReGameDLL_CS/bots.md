# Использование ботов

ReGameDLL_CS включает код zBot из Counter-Strike: Condition Zero. На выделенном сервере ботов необходимо включить явно, а серверу CS 1.6 также нужны отдельные профили и ресурсы.

:::warning Устаревший параметр запуска

Не используйте старый параметр HLDS `-bots`. Он удалён в пользу CVar `bot_enable`.

:::

## Включение ботов в CS 1.6

1. Установите актуальный выпуск ReGameDLL_CS.
2. Скачайте официальный архив [`bot_profiles.zip`](https://github.com/rehlds/ReGameDLL_CS/raw/refs/heads/master/regamedll/extra/zBot/bot_profiles.zip).
3. Распакуйте архив в корень сервера так, чтобы его файлы `cstrike` объединились с `<server>/cstrike`.
4. Создайте или отредактируйте `<server>/cstrike/game_init.cfg` и добавьте:

```text
bot_enable "1"
```

5. Полностью перезапустите сервер.

Обычный архив `regamedll-bin-*.zip` не содержит профили ботов для CS 1.6, поэтому установки одной GameDLL недостаточно.

## Включение ботов в Condition Zero

В Condition Zero стандартные профили и ресурсы zBot уже входят в игру. На выделенном сервере измените `<server>/czero/game_init.cfg`:

```text
bot_enable "1"
```

После этого полностью перезапустите сервер. На listen-серверах zBot включён независимо от значения этой CVar.

## Добавление и удаление ботов

Выполняйте команды в консоли сервера или через RCON:

| Команда | Результат |
| --- | --- |
| `bot_add` | Добавляет случайного бота с учётом предпочтения `bot_join_team`. |
| `bot_add <profile>` | Добавляет указанный профиль из `BotProfile.db`. |
| `bot_add_t [profile]` | Добавляет случайного или указанного бота-террориста. |
| `bot_add_ct [profile]` | Добавляет случайного или указанного бота-контртеррориста. |
| `bot_kill` или `bot_kill all` | Убивает всех живых ботов, не удаляя их. |
| `bot_kill <name>` | Убивает одного бота. Имена с пробелами заключайте в кавычки. |
| `bot_kick` или `bot_kick all` | Удаляет всех ботов и сбрасывает квоту, чтобы они не добавились снова сразу же. |
| `bot_kick <name>` | Удаляет одного бота и уменьшает квоту. |
| `bot_about` | Показывает информацию о реализации ботов. |

При ручном добавлении бота `bot_quota` увеличивается, а при ручном удалении — уменьшается.

## Настройка количества ботов

`bot_quota_mode` определяет, как интерпретируется `bot_quota`.

### Всегда шесть ботов

```text
bot_quota_mode "normal"
bot_quota "6"
bot_join_after_player "0"
```

### Всего десять активных игроков

В режиме `fill` общее число людей и ботов поддерживается около квоты:

```text
bot_quota_mode "fill"
bot_quota "10"
```

### Два бота на каждого человека

В режиме `match` квота задаёт отношение количества людей к ботам:

```text
bot_quota_mode "match"
bot_quota "2"
```

Полезные настройки квоты:

| CVar | Значения | Назначение |
| --- | --- | --- |
| `bot_join_after_player` | `0`, `1`, `2` | `0`: боты могут войти на пустой сервер. `1`: ожидать человека в T/CT. `2`: ожидать любого подключённого человека, включая наблюдателей. |
| `bot_join_delay` | секунды | Задерживает вход ботов после смены карты. |
| `bot_auto_vacate` | `0` или `1` | При включении оставляет свободное место для человека. |
| `bot_join_team` | `any`, `T`, `CT` | Предпочтительная команда для автоматически добавленных ботов. |

## Сложность, разговоры и задачи

```text
bot_difficulty "2"
bot_chatter "minimal"
bot_defer_to_human "0"
```

- `bot_difficulty`: `0` — легко, `1` — нормально, `2` — сложно, `3` — эксперт.
- `bot_chatter`: обычно `off`, `radio`, `minimal` или `normal`.
- `bot_defer_to_human 0`: боты могут выполнять задачи сценария.
- `bot_deathmatch 1`: боты используют поведение deathmatch и не выполняют обычный сценарий.
- `bot_freeze 1`: запрещает ботам двигаться, что удобно для тестирования.

Также доступны наборы ограничений оружия:

```text
bot_knives_only
bot_pistols_only
bot_snipers_only
bot_all_weapons
```

## Навигация на пользовательских картах

Ботам нужен файл навигации `<mod>/maps/<map>.nav`. Если у пользовательской карты его нет, выполните:

```text
bot_nav_analyze
```

Анализ навигации может занять время и создаёт новый файл `.nav`. Текущие сборки ReGameDLL_CS загружают созданную навигацию после анализа без отдельного перезапуска карты.

Перед повторным анализом создайте резервную копию вручную изменённых `.nav`. Дополнительные команды `bot_nav_*` предназначены для опытных пользователей; применяйте их на тестовом сервере.

## Пример конфигурации ботов

После включения ботов в `game_init.cfg` поместите повседневные настройки в `game.cfg` или отдельный файл, выполняемый серверной конфигурацией:

```text
bot_quota_mode "fill"
bot_quota "12"
bot_join_after_player "2"
bot_join_delay "5"
bot_auto_vacate "1"
bot_difficulty "2"
bot_chatter "minimal"
bot_defer_to_human "0"
```

Если команды `bot_*` неизвестны или боты не входят, см. раздел [Устранение неполадок](../troubbleshouting/).
