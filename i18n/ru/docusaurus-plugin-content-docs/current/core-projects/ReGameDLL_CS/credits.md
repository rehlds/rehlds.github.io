# Проект и лицензия

ReGameDLL_CS поддерживается сообществом ReHLDS. Проект восстанавливает и расширяет серверную GameDLL Counter-Strike/Condition Zero, предоставляя администраторам серверов и разработчикам плагинов поддерживаемую и доступную для изучения реализацию.

- [Последний стабильный выпуск](https://github.com/rehlds/ReGameDLL_CS/releases/latest)
- [Трекер задач](https://github.com/rehlds/ReGameDLL_CS/issues)

## Лицензия

Текущий исходный код распространяется по лицензии, включённой в исходный репозиторий. В 2025 году ReGameDLL_CS перешла на лицензию MIT; перед распространением исходного кода или бинарных файлов сверяйтесь с актуальным файлом [`LICENSE`](https://github.com/rehlds/ReGameDLL_CS/blob/master/LICENSE) в репозитории.

Valve, Counter-Strike, Half-Life и связанные названия и ресурсы принадлежат их владельцам. ReGameDLL_CS не содержит все коммерческие игровые данные, необходимые для запуска сервера.
