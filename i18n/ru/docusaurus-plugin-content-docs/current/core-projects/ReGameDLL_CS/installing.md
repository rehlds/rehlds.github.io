# Установка и обновление

Эти инструкции предназначены для выделенных серверов Counter-Strike 1.6 и Counter-Strike: Condition Zero на Windows и 32-разрядной Linux.

## Перед началом

1. Полностью остановите сервер.
2. Создайте резервную копию каталога мода (`cstrike` или `czero`), особенно папки `dlls` и файлов конфигурации.
3. Скачайте `regamedll-bin-*.zip` из [последнего стабильного выпуска](https://github.com/rehlds/ReGameDLL_CS/releases/latest).

:::note

На странице выпуска также есть файл `.zip.asc`. Это подпись для проверки, а не пакет сервера.

:::

## Выбор сборки для платформы

| Платформа сервера | Папка в архиве | Основной файл |
| --- | --- | --- |
| Windows | `bin/win32/cstrike` | `dlls/mp.dll` |
| Linux x86 | `bin/linux32/cstrike` | `dlls/cs.so` |

В архиве для обеих поддерживаемых игр используется имя папки `cstrike`. При установке на Condition Zero копируйте содержимое этой папки в каталог `czero` сервера.

## Установка в Windows

1. Откройте `bin/win32/cstrike` в скачанном архиве.
2. Скопируйте содержимое в каталог нужного мода:
   - CS 1.6: `<server>/cstrike`
   - Condition Zero: `<server>/czero`
3. Убедитесь, что файл `<mod>/dlls/mp.dll` заменён.
4. Объедините файлы конфигурации, как описано ниже.

## Установка в Linux

Распакуйте архив и скопируйте Linux-сборку в каталог нужного мода. Например, для CS 1.6:

```bash
unzip regamedll-bin-*.zip
cp -a bin/linux32/cstrike/. /path/to/server/cstrike/
```

Для Condition Zero используйте каталог `/path/to/server/czero/`. Убедитесь, что `<mod>/dlls/cs.so` заменён и доступен для чтения пользователю, от имени которого работает сервер.

## Объединение конфигураций

Не перезаписывайте без проверки уже настроенные конфигурации.

| Файл | Назначение |
| --- | --- |
| `game.cfg` | Настройки игрового процесса и дополнительные CVar ReGameDLL_CS. |
| `game_init.cfg` | Ранние настройки GameDLL, например `bot_enable` и `hostage_ai_enable`. |
| `delta.lst` | Описания сетевых дельт из текущей сборки. Файл должен соответствовать выпуску. |

При первой установке скопируйте все три файла. При обновлении:

1. Замените GameDLL и `delta.lst` версиями из выпуска.
2. Сравните свои `game.cfg` и `game_init.cfg` с новыми файлами.
3. Добавьте новые CVar и комментарии, сохранив выбранные вами значения.

Актуальные исходные шаблоны: [`game.cfg`](https://github.com/rehlds/ReGameDLL_CS/blob/master/dist/game.cfg) и [`game_init.cfg`](https://github.com/rehlds/ReGameDLL_CS/blob/master/dist/game_init.cfg).

## Запуск и проверка

Запустите сервер и выполните:

```text
game version
```

Если команда неизвестна, новая GameDLL не загрузилась. Проверьте файл для выбранной платформы, каталог мода, права доступа и параметры `gamedll` / `gamedll_linux` в файле `liblist.gam` мода.

## Обновление установленной версии

Используйте тот же порядок действий: остановите сервер, сделайте резервную копию, замените GameDLL и `delta.lst`, объедините изменения конфигурации и проверьте результат командой `game version`.

Перед обновлением прочитайте [примечания к выпускам](https://github.com/rehlds/ReGameDLL_CS/releases). Новые версии могут добавлять CVar или менять поведение API, от которого зависят ReAPI и серверные плагины.

## Необязательный beta-режим

ReGameDLL_CS сохраняет необязательный beta-режим с последними изменениями из официальной версии Counter-Strike от Valve. Добавляйте `-beta` в командную строку HLDS только для осознанного тестирования этого режима. Перед использованием на рабочем сервере проверьте совместимость плагинов.
