# ReGameDLL_CS

ReGameDLL_CS — это реконструированная и активно поддерживаемая замена серверной GameDLL Counter-Strike (`mp.dll` в Windows и `cs.so` в Linux). Проект основан на оригинальной GameDLL Counter-Strike из HLDS build 6153 beta и добавляет исправления, новые серверные настройки, встроенных ботов и расширенный API для модов и плагинов.

Проект поддерживает официальные серверные файлы Valve для:

- Counter-Strike 1.6 (`cstrike`)
- Counter-Strike: Condition Zero (`czero`)

Для рабочих серверов используйте [последний стабильный выпуск](https://github.com/rehlds/ReGameDLL_CS/releases/latest). Сборки в разработке доступны в [GitHub Actions](https://github.com/rehlds/ReGameDLL_CS/actions/workflows/build.yml), но могут содержать изменения, ещё не вошедшие в стабильный выпуск.

## Возможности ReGameDLL_CS

- Исправления игрового процесса и серверных ошибок.
- Дополнительные игровые правила и настраиваемые CVar.
- Встроенная поддержка zBot, включая режимы квоты и инструменты навигации.
- Улучшенный ИИ заложников из Condition Zero, который можно установить и для CS 1.6.
- Новые серверные команды, например `game version`, `endround` и `swapteams`.
- Расширенный API GameDLL, используемый такими проектами, как [ReAPI](https://github.com/rehlds/ReAPI).

Полный и постоянно обновляемый список настроек находится в исходном файле [`game.cfg`](https://github.com/rehlds/ReGameDLL_CS/blob/master/dist/game.cfg).

## Предупреждение о совместимости

:::warning Бинарная совместимость

ReGameDLL_CS не совместима на бинарном уровне с оригинальной GameDLL Valve, поскольку собрана другими компиляторами. Плагины, которые ищут или изменяют оригинальный бинарный файл по сигнатурам либо смещениям, включая некоторые плагины на базе Orpheu, могут не работать или вызывать падение сервера.

Используйте поддерживаемые API, например ReAPI, и проверяйте каждый бинарно-зависимый плагин до установки на рабочий сервер.

:::

Обычные плагины AMX Mod X и Metamod, использующие документированные интерфейсы, как правило, этим ограничением не затрагиваются.

## Файлы выпуска

Стабильный архив `regamedll-bin-*.zip` содержит отдельные сборки для `win32` и `linux32`:

| Платформа | GameDLL | Путь в архиве |
| --- | --- | --- |
| Windows | `mp.dll` | `bin/win32/cstrike/dlls/mp.dll` |
| Linux x86 | `cs.so` | `bin/linux32/cstrike/dlls/cs.so` |

В каждой папке платформы также находятся `game.cfg`, `game_init.cfg` и `delta.lst`. Профили и звуки zBot для CS 1.6 распространяются отдельно; см. раздел [Использование ботов](./bots/).
