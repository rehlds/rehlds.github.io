# Настройки

## `config.ini`

В файле `addons/resemiclip/config.ini` хранятся общесерверные значения по умолчанию в виде строк `ключ = значение;`:

| Ключ | Диапазон | По умолчанию (в поставке) | Назначение |
| --- | --- | --- | --- |
| `semiclip` | `0`–`1` | `1` | Выключает и включает semiclip. |
| `team` | `0`–`3` | `3` | На кого распространяется: `0` — на всех, `1` — только на террористов, `2` — только на контртеррористов, `3` — только на союзников по команде. |
| `time` | `0`–`180` | `0` | Число секунд с начала раунда, в течение которых действует semiclip. Значение `0` означает, что он действует постоянно, а не только в этом промежутке. |
| `crouch` | `0`–`1` | `1` | Позволяет запрыгивать на присевшего игрока. |
| `effects` | `0`–`1` | `0` | Нужно ли изменять прозрачность игрока в зависимости от расстояния между игроками. |
| `distance` | `64`–`250` | `200` | Расстояние (в единицах), на котором применяются прозрачность и эффект semiclip. |
| `transparency` | `0`–`255` | `120` | Уровень прозрачности игрока, пока действует semiclip. |
| `penetfire` | `0`–`1` | `0` | Разрешает пулям проходить сквозь союзников, на которых действует semiclip. |

Значения вне диапазона не отбрасываются, а приводятся к ближайшей допустимой границе.

## Переопределения для карт и префиксов

ReSemiclip загружает конфигурацию в следующем порядке, причём каждый шаг переопределяет только те ключи, которые в нём заданы:

1. `addons/resemiclip/config.ini` — общесерверные значения по умолчанию.
2. `addons/resemiclip/maps/prefix_<префикс>.ini`, где `<префикс>` — это часть имени текущей карты до первого подчёркивания (например, `de` для `de_dust2`).
3. `addons/resemiclip/maps/<имя карты>.ini` — точное имя текущей карты (например, `de_dust2.ini`).

:::note

Примеры файлов в каталоге `maps/` (`_de_dust2.ini`, `_prefix_de.ini`) намеренно названы с ведущим подчёркиванием — такие имена ReSemiclip не ищет. Это неактивные шаблоны; чтобы задействовать их, переименуйте файлы в точные ожидаемые имена (`de_dust2.ini`, `prefix_de.ini`).

:::

## Консольная команда для изменения на лету

```text
semiclip_option <key> <value>
```

Изменяет одну настройку во время работы сервера, используя те же ключи, что и `config.ini` (например, `semiclip_option time 5`). Чтобы вместо этого вывести действующие сейчас настройки, выполните `semiclip_option` без аргументов или с несуществующим ключом.
