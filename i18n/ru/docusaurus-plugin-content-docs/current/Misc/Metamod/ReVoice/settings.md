# Настройки

ReVoice настраивается через файл `addons/revoice/revoice.cfg`, который при запуске выполняется командой `exec` как обычная серверная конфигурация — это список присваиваний консольных переменных, а не INI-файл.

## Консольные переменные

| CVar | По умолчанию | Назначение |
| --- | --- | --- |
| `REV_DefaultCodec` | `speex` | Кодек, в который ReVoice перекодирует исходящий голос обычных игроков. Принимает `speex` или `opus`. |
| `REV_HltvCodec` | `opus` | Кодек, в который ReVoice перекодирует исходящий голос HLTV. Принимает `speex` или `opus`. |
| `revoice_version` | *(текущая версия)* | Только для чтения; сообщает версию загруженного ReVoice. |

Конфигурация, поставляемая по умолчанию:

```text
REV_HltvCodec opus		// speex, opus
REV_DefaultCodec speex	// speex, opus
```

Изменения переменных вступают в силу немедленно — ReVoice отслеживает изменения обеих переменных с кодеками и применяет их без перезапуска.

:::note

`sv_voiceenable` — это стандартная переменная движка, а не настройка ReVoice; чтобы голосовой чат вообще работал, она должна быть равна `1`. ReVoice лишь устраняет несовместимость кодеков между Steam- и не-Steam-клиентами, когда голосовой чат уже включён.

:::

## Консольная команда

```text
rev version
rev status
```

- `rev version` — выводит версию загруженного ReVoice, дату сборки и коммит.
- `rev status` — выводит подробное состояние во время работы (добавлена специально для диагностики проблем с голосом).
