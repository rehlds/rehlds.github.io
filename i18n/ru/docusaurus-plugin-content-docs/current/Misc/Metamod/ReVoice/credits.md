# Авторы

ReVoice — плагин Metamod, изначально созданный The Legion и с тех пор поддерживаемый сообществом ReHLDS.

:::warning Устаревший проект

Сопровождающие пометили ReVoice как **устаревший**; активно он не развивается.

:::

## Лицензия

ReVoice распространяется по лицензии [GNU General Public License v3.0](https://github.com/rehlds/ReVoice/blob/master/LICENSE). В каталоге `external/` он включает библиотеки кодеков Speex, SILK и Opus, каждая из которых распространяется по собственной лицензии.

## Как помочь проекту

Учитывая статус устаревшего, особенно полезны тестирование и сообщения об ошибках через [трекер задач](https://github.com/rehlds/ReVoice/issues). Указывайте версию ReHLDS, содержимое `revoice.cfg` и вывод `rev status`. Pull-запросы также приветствуются.
