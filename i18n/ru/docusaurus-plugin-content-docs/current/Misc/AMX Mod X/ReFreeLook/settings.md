# Настройки

У ReFreeLook есть единственная консольная переменная.

## `afl_admin_access_flags`

Флаги доступа, выводящие игрока из-под навязанного сервером режима камеры наблюдателя (`mp_forcecamera`/`mp_forcechasecam`). Игрок, в чьём уровне доступа AMX Mod X присутствует **любой** из перечисленных флагов, получает неограниченное управление камерой в режиме наблюдения. Флаги складываются — сочетайте сколько угодно букв.

| По умолчанию |
| --- |
| `d` |

Используются стандартные флаги доступа AMX Mod X (описанные в `users.ini`):

| Флаг | Права |
| --- | --- |
| `a` | Иммунитет (игрока нельзя кикнуть, забанить, убить или шлёпнуть, а также применить к нему другие команды администратора). |
| `b` | Резервирование (можно подключаться на зарезервированные слоты). |
| `c` | Команда `amx_kick`. |
| `d` | Команды `amx_ban` и `amx_unban` (постоянные и временные баны). |
| `e` | Команды `amx_slay` и `amx_slap`. |
| `f` | Команда `amx_map`. |
| `g` | Команда `amx_cvar` (доступны не все переменные). |
| `h` | Команда `amx_cfg`. |
| `i` | Команда `amx_chat` и другие команды чата. |
| `j` | Команда `amx_vote` и другие команды голосования. |
| `k` | Доступ к переменной `sv_password` (через `amx_cvar`). |
| `l` | Доступ к команде `amx_rcon` и переменной `rcon_password` (через `amx_cvar`). |
| `m`–`t` | Пользовательские уровни A–H для дополнительных плагинов. |
| `u` | Доступ к меню. |
| `v` | `amx_ban`/`amx_unban`, только временные баны (для `amx_unban` — только баны, выданные самим игроком в течение текущей карты). |
| `z` | Обычный пользователь (без прав администратора). |

Поскольку по умолчанию указан флаг `d` (команды бана), большинству серверов стоит добавить те флаги, которыми реально пользуется их группа модераторов или администраторов, например:

```text
afl_admin_access_flags "cd"
```

Такая настройка даёт свободную камеру всем, у кого есть флаг кика (`c`) или бана (`d`).
