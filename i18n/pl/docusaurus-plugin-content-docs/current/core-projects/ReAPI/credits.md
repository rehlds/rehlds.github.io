# Autorzy

ReAPI to moduł AMX Mod X utrzymywany przez społeczność ReHLDS. Udostępnia wnętrzności [ReHLDS](/pl/docs/rehlds) i [ReGameDLL_CS](/pl/docs/regamedll-cs) wtyczkom w Pawnie poprzez łańcuchy hooków, dostęp do składowych i funkcje natywne sprawdzające możliwości, dzięki czemu autorzy wtyczek nie muszą sami grzebać w przesunięciach pamięci.

## Jak możesz pomóc

Uruchom ReAPI na swoim serwerze gry i zgłaszaj napotkane problemy przez [system zgłoszeń](https://github.com/rehlds/ReAPI/issues), podając swoje wersje AMX Mod X, ReHLDS i ReGameDLL_CS, listę wtyczek oraz kroki pozwalające odtworzyć problem. Pull requesty również są mile widziane.
