# Autorzy

ReHLDS powstał dzięki inżynierii wstecznej oryginalnego HLDS (wersja 6152/6153), przeprowadzonej na podstawie informacji diagnostycznych DWARF zawartych w linuksowej wersji HLDS (`engine_i486.so`). Po drodze opiekunowie projektu i osoby, które do niego dołożyły swój wkład, znalazły i naprawiły dużą liczbę usterek i potencjalnych błędów oryginalnego silnika. Projekt jest utrzymywany przez społeczność ReHLDS jako niekomercyjne przedsięwzięcie o otwartym kodzie.
