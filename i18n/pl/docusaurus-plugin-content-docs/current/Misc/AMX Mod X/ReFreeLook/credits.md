# Autorzy

ReFreeLook to moduł AMX Mod X autorstwa s1lentq, utrzymywany przez społeczność ReHLDS, oparty pierwotnie na [AdminFreeLook autorstwa Arkshine’a](https://github.com/Arkshine/AdminFreeLook).

## Jak możesz pomóc

Uruchom ReFreeLook na swoim serwerze gry i zgłaszaj problemy przez [system zgłoszeń](https://github.com/rehlds/ReFreeLook/issues), podając swoje wersje ReGameDLL_CS i AMX Mod X oraz wartość cvara `afl_admin_access_flags`. Pull requesty również są mile widziane.
