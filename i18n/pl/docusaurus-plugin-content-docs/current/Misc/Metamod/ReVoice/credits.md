# Autorzy

ReVoice to wtyczka Metamoda stworzona pierwotnie przez The Legion i utrzymywana od tamtej pory przez społeczność ReHLDS.

:::warning Projekt porzucony

ReVoice został oznaczony przez opiekunów jako **porzucony** i nie jest aktywnie rozwijany.

:::

## Jak możesz pomóc

Skoro projekt jest porzucony, testy i zgłoszenia błędów przez [system zgłoszeń](https://github.com/rehlds/ReVoice/issues) są tym cenniejsze. Podaj swoją wersję ReHLDS, plik `revoice.cfg` i wynik polecenia `rev status`. Pull requesty również są mile widziane.
