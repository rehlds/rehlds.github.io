# 欢迎阅读 ReHLDS 文档

ReHLDS 项目由一系列经过重新工程化和优化的组件组成，旨在改善 Half-Life 专用服务器（HLDS）的运行体验，尤其适用于 Counter-Strike 1.6 以及其他基于 HLDS 的游戏。这些项目在性能、安全性、可定制性和扩展性方面提供了多项改进，为游戏服务器带来更现代、更稳健的平台。

## ReHLDS 生态系统包含什么

我们的组织维护着多个关键项目。它们既能无缝协同，也能独立运行，共同提升服务器的稳定性、灵活性和功能性。

### ReHLDS

ReHLDS 是对原始 HLDS 引擎进行逆向工程后重构的版本，旨在提供更安全、更高效、更易定制的服务器体验。ReHLDS 基于原始的 HLDS 6153 版本构建，带来了多项性能优化、更丰富的配置选项以及更完善的网络处理能力。

### Metamod-r

Metamod-r 是原始 Metamod 的优化版本，在 HLDS 引擎和游戏模组之间充当动态插件管理器。它让服务器无需重启即可加载或卸载插件，使服务器定制更加灵活。Metamod-r 同时兼容 HLDS 和 ReHLDS，并提供经过改进的核心、更高的性能以及即时（JIT）编译器。

### ReGameDLL_CS

ReGameDLL_CS 是对 Counter-Strike GameDLL 重新工程化后的版本，为服务器管理员和模组开发者提供了一个更强大、更稳定的基础，用于运行 Counter-Strike 1.6 和 Condition Zero 服务器。它提供扩展 API、更多游戏设置和更完善的安全机制，从而支持高级修改，并让管理员能够更深入地控制服务器设置。

### ReAPI

ReAPI 是一个 AMX Mod X 模块，为 ReHLDS、ReGameDLL 和 Metamod 插件（例如 ReUnion、ReVoice）提供 API。

## 为什么选择 ReHLDS 系列项目？

ReHLDS 套件面向希望获得更多控制权、更高稳定性和高级定制能力的 HLDS 服务器管理员、模组开发者及其他开发人员。在专业开发者的持续维护和社区贡献下，ReHLDS 组件可靠且兼容性良好，非常适合用于维护满足当今游戏需求的高性能服务器。
