# 设置

:::warning 已废弃

此处记录仅供参考。该项目已归档——参见[什么是 LocalizeBug Fix？](./index.md)。

:::

LocalizeBug Fix **没有任何配置**。它既不注册控制台变量也不注册命令，更不附带配置文件。加载插件即启用防护；没有任何可调之处。

这正是它与现代替代品的一处明显差别：[SafeNameAndChat](/zh-Hans/docs/safenameandchat/settings) 提供了十一个变量，可以分别选择在昵称和聊天中净化哪些字符。LocalizeBug Fix 则是要么全开、要么全不开。

:::note

如果你是因为该插件妨碍了什么、想让它的行为温和一些才来看这一页——没有这样的设置，可选项只有装或不装。在当前的服务器上请使用 [SafeNameAndChat](/zh-Hans/docs/safenameandchat)，那里可以单独关闭各项防护。

:::
