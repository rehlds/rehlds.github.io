# 致谢

LocalizeBug Fix 由 [@s1lentq](https://github.com/s1lentq) 编写，他同时也是 ReHLDS 组织多个核心项目的作者。该插件自报名称为 *LocalizeBug Fix*，版本 `2.4`，日期为 2014 年。

:::warning 已废弃

该仓库已在 GitHub 上**归档**——它是只读的，不再接受问题或 Pull Request。在当前的服务器上请改用 [SafeNameAndChat](/zh-Hans/docs/safenameandchat)。

:::

## 沿革

- **LocalizeBug Fix**——本项目，面向原版 HLDS。
- [**ReLocalizeBug Fix**](/zh-Hans/docs/relocalizebugfix)——ReHLDS 组织为 ReHLDS 所做的扩展版，自 2017 年起废弃。
- [**SafeNameAndChat**](/zh-Hans/docs/safenameandchat)——当下覆盖这一类漏洞、仍在维护的第三方插件。

仓库中没有 `LICENSE` 文件，因此这份代码未声明任何许可条款。如果你打算复用其中的任何部分，请据此谨慎处理。

Valve、Half-Life、Counter-Strike 及相关名称和素材归各自所有者所有。

本项目不再接受新的工作——仓库已归档。请改为参与 [SafeNameAndChat](https://github.com/WPMGPRoSToTeMa/SafeNameAndChat)。
