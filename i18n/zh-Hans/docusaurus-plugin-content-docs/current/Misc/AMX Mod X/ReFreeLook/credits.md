# 致谢

ReFreeLook 是由 s1lentq 编写、并由 ReHLDS 社区维护的 AMX Mod X 模块，最初基于 [Arkshine 的 AdminFreeLook](https://github.com/Arkshine/AdminFreeLook)。

## 项目链接

- [源代码仓库](https://github.com/rehlds/ReFreeLook)
- [发行版](https://github.com/rehlds/ReFreeLook/releases)
- [问题追踪器](https://github.com/rehlds/ReFreeLook/issues)
- [更新日志](https://github.com/rehlds/ReFreeLook/blob/master/CHANGELOG.md)
- [ReHLDS 组织](https://github.com/rehlds)

## 许可证

ReFreeLook 以 [GNU General Public License v3.0](https://github.com/rehlds/ReFreeLook/blob/master/LICENSE) 分发。

## 如何参与

在你的游戏服务器上运行 ReFreeLook，并通过[问题追踪器](https://github.com/rehlds/ReFreeLook/issues)反馈任何问题，附上你的 ReGameDLL_CS 与 AMX Mod X 版本，以及 `afl_admin_access_flags` 的取值。同样欢迎提交 Pull Request。
