## 如何参与

在你的游戏服务器上运行 ReChecker，并通过[问题追踪器](https://github.com/rehlds/ReChecker/issues)反馈任何问题，附上你的 ReHLDS 与 Metamod 版本，以及 `resources.ini` 中相关的部分。同样欢迎提交 Pull Request。
