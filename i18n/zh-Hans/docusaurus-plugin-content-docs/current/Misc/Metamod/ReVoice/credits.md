# 致谢

ReVoice 是一个 Metamod 插件，最初由 The Legion 创建，此后由 ReHLDS 社区维护。

:::warning 已废弃

维护者已把 ReVoice 标记为**已废弃**，该项目不再积极开发。

:::

## 项目链接

- [源代码仓库](https://github.com/rehlds/ReVoice)
- [发行版](https://github.com/rehlds/ReVoice/releases)
- [问题追踪器](https://github.com/rehlds/ReVoice/issues)
- [更新日志](https://github.com/rehlds/ReVoice/blob/master/CHANGELOG.md)
- [ReHLDS 组织](https://github.com/rehlds)

## 许可证

ReVoice 以 [GNU General Public License v3.0](https://github.com/rehlds/ReVoice/blob/master/LICENSE) 分发。它在 `external/` 目录中打包了 Speex、SILK 和 Opus 编解码库，各自遵循其自身的许可证。

## 如何参与

鉴于它已处于废弃状态，通过[问题追踪器](https://github.com/rehlds/ReVoice/issues)提供测试和缺陷报告尤其有价值。请附上你的 ReHLDS 版本、`revoice.cfg` 以及 `rev status` 的输出。同样欢迎提交 Pull Request。
