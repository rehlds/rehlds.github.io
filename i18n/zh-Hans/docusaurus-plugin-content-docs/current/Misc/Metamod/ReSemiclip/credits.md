# 致谢

ReSemiclip 是一个 Metamod 插件，最初由 s1lent 编写，此后由 ReHLDS 社区维护，其参考实现为 [joaquimandrade 的 Semiclip 模块](https://github.com/joaquimandrade)。

## 项目链接

- [源代码仓库](https://github.com/rehlds/ReSemiclip)
- [发行版](https://github.com/rehlds/ReSemiclip/releases)
- [问题追踪器](https://github.com/rehlds/ReSemiclip/issues)
- [更新日志](https://github.com/rehlds/ReSemiclip/blob/master/CHANGELOG.md)
- [ReHLDS 组织](https://github.com/rehlds)

## 许可证

ReSemiclip 以 [GNU General Public License v3.0](https://github.com/rehlds/ReSemiclip/blob/master/LICENSE) 分发。

## 如何参与

在你的游戏服务器上运行 ReSemiclip，并通过[问题追踪器](https://github.com/rehlds/ReSemiclip/issues)反馈任何问题，附上你的 ReHLDS 与 ReGameDLL_CS 版本，以及 `config.ini` 中相关的部分。同样欢迎提交 Pull Request。
