# 致谢

ReAPI 是由 ReHLDS 社区维护的 AMX Mod X 模块。它通过钩子链、结构体成员访问和能力检测原生函数，把 [ReHLDS](/zh-Hans/docs/rehlds) 和 [ReGameDLL_CS](/zh-Hans/docs/regamedll-cs) 的内部实现开放给 Pawn 插件，使插件作者无需自行修补内存偏移。

## 如何参与

在你的游戏服务器上运行 ReAPI，并通过[问题追踪器](https://github.com/rehlds/ReAPI/issues)反馈遇到的任何问题，附上你的 AMX Mod X、ReHLDS 和 ReGameDLL_CS 版本、插件列表以及复现步骤。同样欢迎提交 Pull Request。
