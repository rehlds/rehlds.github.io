# 致谢

ReHLDS 是对原版 HLDS（build 6152/6153）进行逆向工程的成果，其依据是 HLDS Linux 版本（`engine_i486.so`）中内置的 DWARF 调试信息。在此过程中，项目的维护者和贡献者发现并修复了原始引擎中大量的缺陷与潜在问题。项目由 ReHLDS 社区以非商业、开源的方式维护。

## 如何参与

在你的游戏服务器上运行 ReHLDS，并通过[问题追踪器](https://github.com/rehlds/ReHLDS/issues)反馈遇到的任何问题——反馈中应包含哪些内容，请参见[故障排查](./troubleshuting.md)。同样欢迎提交 Pull Request。
