# 致谢

**Metamod-r** 基于 _Will Day_ 为 Half-Life 1 编写的原版 [Metamod](http://metamod.org/)，并吸收了 [Jussi Kivilinna](https://github.com/jkivilin)（[Metamod-p](https://github.com/jkivilin/metamod-p)）的若干改进。本项目包含大量性能优化，代码也更为整洁，其核心使用 JIT 编译器实现。

**Metamod-r 与原版 `HLDS` 不兼容。必须事先安装 [ReHLDS](https://github.com/rehlds/ReHLDS)（`API 3.1+`）。在其他环境下无法保证该产品能够正常工作。**

以 [![GitHub license](https://img.shields.io/github/license/rehlds/metamod-r.svg?style=flat-square)](https://github.com/rehlds/metamod-r/blob/master/LICENSE) 分发。
