# Setări

:::warning Abandonat

Păstrat ca referință. Proiectul este arhivat — citiți [Ce este LocalizeBug Fix?](./index.md).

:::

LocalizeBug Fix **nu avea nicio configurație**. El nu înregistra cvar-uri și nici comenzi de consolă și nu distribuia niciun fișier de configurare. Încărcarea pluginului activa protecția; nu era nimic de reglat.

Aceasta este o deosebire reală față de înlocuitorul lui modern: [SafeNameAndChat](/ro/docs/safenameandchat/settings) pune la dispoziție unsprezece cvar-uri, ca să alegeți ce caractere sunt curățate în nume și ce caractere în discuții. LocalizeBug Fix era totul sau nimic.

:::note

Dacă ați ajuns pe această pagină sperând să îmblânziți comportamentul pluginului, fiindcă vă încurcă la ceva, nu există nicio setare pentru asta — singurele variante sunt să îl încărcați sau nu. Pe un server actual, folosiți [SafeNameAndChat](/ro/docs/safenameandchat), unde protecțiile individuale pot fi dezactivate.

:::
