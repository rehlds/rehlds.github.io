# Credite

ReAMXModX este un fork al **AMX Mod X**, creat și întreținut de [AlliedModders](https://www.amxmodx.org/). Toată munca de fond din acest depozit le aparține; forkul adaugă legăturile de SDK pentru ReHLDS și ReGameDLL peste un instantaneu din august 2016 al ramurii de dezvoltare `1.8.3` (`git5067`).

Mașina abstractă și compilatorul Pawn distribuite cu AMX Mod X sunt © ITB CompuPhase, 1997–2005.

:::warning Abandonat

Forkul este **învechit** — AMX Mod X oficial susține ReHLDS în mod nativ. Folosiți în schimb [AMX Mod X](https://www.amxmodx.org/).

:::

## Licență

Licențierea urmează AMX Mod X oficial. Textele licențelor se află în depozit, în `public/licenses/` — `LICENSE.txt`, alături de copii ale GPL v2 și v3, plus `ACKNOWLEDGEMENTS.txt` pentru compilatorul Pawn inclus. Consultați aceste fișiere, precum și AMX Mod X oficial, înainte de a redistribui ceva construit din acest arbore.

Valve, Half-Life, Counter-Strike și numele și materialele asociate aparțin deținătorilor lor de drept.

## Cum puteți ajuta

Acest fork nu mai primește contribuții noi. Contribuiți la [AMX Mod X oficial](https://github.com/alliedmodders/amxmodx) sau — pentru a ajunge la mecanismele interne ale ReHLDS și ReGameDLL_CS din Pawn, pe un server modern — la [ReAPI](/ro/docs/reapi).
