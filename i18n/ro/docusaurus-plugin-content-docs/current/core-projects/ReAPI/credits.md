# Credite

ReAPI este un modul AMX Mod X întreținut de comunitatea ReHLDS. El expune mecanismele interne ale [ReHLDS](/ro/docs/rehlds) și ale [ReGameDLL_CS](/ro/docs/regamedll-cs) către pluginurile Pawn, prin lanțuri de hook-uri, accesori de membri și funcții native de verificare a capabilităților, astfel încât autorii de pluginuri să nu mai fie nevoiți să modifice singuri decalaje de memorie.

## Cum puteți ajuta

Rulați ReAPI pe serverul dumneavoastră de joc și raportați problemele întâlnite prin [sistemul de raportare](https://github.com/rehlds/ReAPI/issues), indicând versiunile dumneavoastră de AMX Mod X, ReHLDS și ReGameDLL_CS, lista pluginurilor și pașii de reproducere. Sunt binevenite și pull request-urile.
