# Proiect și licență

ReGameDLL_CS este întreținut de comunitatea ReHLDS. El reconstruiește și extinde GameDLL-ul de server al Counter-Strike/Condition Zero, pentru ca administratorii de server și dezvoltatorii de pluginuri să dispună de o implementare întreținută și verificabilă.

## Legături ale proiectului

- [Depozitul codului sursă](https://github.com/rehlds/ReGameDLL_CS)
- [Cea mai recentă versiune stabilă](https://github.com/rehlds/ReGameDLL_CS/releases/latest)
- [Sistemul de raportare a problemelor](https://github.com/rehlds/ReGameDLL_CS/issues)
- [Organizația ReHLDS](https://github.com/rehlds)

## Licență

Codul sursă actual este distribuit sub licența inclusă în depozitul oficial. ReGameDLL_CS a trecut la licența MIT în 2025; consultați fișierul [`LICENSE`](https://github.com/rehlds/ReGameDLL_CS/blob/master/LICENSE) actual al depozitului pentru termenii de referință, înainte de a redistribui codul sau binarele.

Valve, Counter-Strike, Half-Life și numele și materialele asociate aparțin deținătorilor lor de drept. ReGameDLL_CS nu include toate datele comerciale ale jocului, necesare pentru a rula un server.
