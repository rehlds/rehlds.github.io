# Credite

**Metamod-r** este bazat pe versiunea originală a [Metamod](http://metamod.org/), scrisă de _Will Day_ pentru Half-Life 1, cu unele îmbunătățiri de la [Jussi Kivilinna](https://github.com/jkivilin) ([Metamod-p](https://github.com/jkivilin/metamod-p)). Acest produs cuprinde un număr mare de optimizări de performanță și un cod mai curat. Nucleul a fost scris cu ajutorul unui compilator JIT.

**Metamod-r este incompatibil cu `HLDS`-ul original. Este necesar să aveți instalat [ReHLDS](https://github.com/rehlds/ReHLDS) (`API 3.1+`). Nu există nicio garanție că produsul va funcționa într-un alt mediu.**

Distribuit sub [![GitHub license](https://img.shields.io/github/license/rehlds/metamod-r.svg?style=flat-square)](https://github.com/rehlds/metamod-r/blob/master/LICENSE).
