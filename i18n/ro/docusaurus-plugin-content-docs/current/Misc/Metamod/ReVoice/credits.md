# Credite

ReVoice este un plugin Metamod creat inițial de The Legion și întreținut de atunci de comunitatea ReHLDS.

:::warning Abandonat

ReVoice este marcat drept **abandonat** de cei care îl întrețin și nu este în dezvoltare activă.

:::

## Cum puteți ajuta

Fiind un proiect abandonat, testele și raportările de erori prin [sistemul de raportare](https://github.com/rehlds/ReVoice/issues) sunt cu atât mai utile. Indicați versiunea dumneavoastră de ReHLDS, fișierul `revoice.cfg` și rezultatul comenzii `rev status`. Sunt binevenite și pull request-urile.
