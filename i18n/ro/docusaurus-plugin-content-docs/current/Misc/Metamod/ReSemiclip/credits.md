# Credite

ReSemiclip este un plugin Metamod scris inițial de s1lent și întreținut de atunci de comunitatea ReHLDS, având [modulul Semiclip al lui joaquimandrade](https://github.com/joaquimandrade) ca implementare de referință.

## Cum puteți ajuta

Rulați ReSemiclip pe serverul dumneavoastră de joc și raportați problemele prin [sistemul de raportare](https://github.com/rehlds/ReSemiclip/issues), indicând versiunile dumneavoastră de ReHLDS și ReGameDLL_CS și partea relevantă din fișierul `config.ini`. Sunt binevenite și pull request-urile.
