# Credite

ReFreeLook este un modul AMX Mod X creat de s1lentq și întreținut de comunitatea ReHLDS, bazat inițial pe [AdminFreeLook al lui Arkshine](https://github.com/Arkshine/AdminFreeLook).

## Legături ale proiectului

- [Depozitul codului sursă](https://github.com/rehlds/ReFreeLook)
- [Versiuni](https://github.com/rehlds/ReFreeLook/releases)
- [Sistemul de raportare a problemelor](https://github.com/rehlds/ReFreeLook/issues)
- [Changelog](https://github.com/rehlds/ReFreeLook/blob/master/CHANGELOG.md)
- [Organizația ReHLDS](https://github.com/rehlds)

## Cum puteți ajuta

Rulați ReFreeLook pe serverul dumneavoastră de joc și raportați problemele prin [sistemul de raportare](https://github.com/rehlds/ReFreeLook/issues), indicând versiunile dumneavoastră de ReGameDLL_CS și AMX Mod X și valoarea cvar-ului `afl_admin_access_flags`. Sunt binevenite și pull request-urile.
