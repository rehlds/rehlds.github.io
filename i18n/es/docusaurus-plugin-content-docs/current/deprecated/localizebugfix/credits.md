# Créditos

LocalizeBug Fix lo escribió [@s1lentq](https://github.com/s1lentq), autor también de varios de los proyectos principales de la organización ReHLDS. El plugin se identificaba como *LocalizeBug Fix* versión `2.4`, fechada en 2014.

:::warning Obsoleto

El repositorio está **archivado** en GitHub: es de solo lectura y no admite incidencias ni pull requests. Usa [SafeNameAndChat](/es/docs/safenameandchat) en un servidor actual.

:::

## Linaje

- **LocalizeBug Fix**: este proyecto, para el HLDS estándar.
- [**ReLocalizeBugFix**](/es/docs/relocalizebugfix): la extensión que hizo la organización ReHLDS para ReHLDS, obsoleta desde 2017.
- [**SafeNameAndChat**](/es/docs/safenameandchat): el plugin de terceros mantenido que cubre hoy esta clase de exploit.

El repositorio no incluye ningún archivo `LICENSE`, así que no hay condiciones de licencia declaradas para este código. Tenlo en cuenta si piensas reutilizar algo de él.

Valve, Half-Life, Counter-Strike y los nombres y materiales relacionados pertenecen a sus respectivos propietarios.

## Cómo colaborar

Este proyecto no admite nuevas aportaciones: el repositorio está archivado. Colabora en [SafeNameAndChat](https://github.com/WPMGPRoSToTeMa/SafeNameAndChat) en su lugar.
