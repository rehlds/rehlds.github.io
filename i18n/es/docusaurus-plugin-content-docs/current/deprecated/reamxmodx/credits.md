# Créditos

ReAMXModX es una bifurcación de **AMX Mod X**, creado y mantenido por [AlliedModders](https://www.amxmodx.org/). Todo el trabajo sustancial de este repositorio es suyo; la bifurcación añade el pegamento del SDK para ReHLDS y ReGameDLL sobre una instantánea de agosto de 2016 del árbol de desarrollo `1.8.3` (`git5067`).

La máquina abstracta y el compilador de Pawn que acompañan a AMX Mod X son © ITB CompuPhase, 1997–2005.

:::warning Obsoleto

La bifurcación está **obsoleta**: el AMX Mod X original admite ReHLDS de forma nativa. Usa [AMX Mod X](https://www.amxmodx.org/).

:::

## Licencia

La licencia es la del AMX Mod X original. Los textos de las licencias están en el repositorio, dentro de `public/licenses/`: `LICENSE.txt` junto a copias de la GPL v2 y v3, además de `ACKNOWLEDGEMENTS.txt` para el compilador de Pawn incluido. Consulta esos archivos, y el propio AMX Mod X, antes de redistribuir nada compilado a partir de este árbol.

Valve, Half-Life, Counter-Strike y los nombres y materiales relacionados pertenecen a sus respectivos propietarios.

## Cómo colaborar

Esta bifurcación no admite nuevas aportaciones. Colabora en [el AMX Mod X original](https://github.com/alliedmodders/amxmodx) o, para acceder desde Pawn a las interioridades de ReHLDS y ReGameDLL_CS en un servidor moderno, en [ReAPI](/es/docs/reapi).
