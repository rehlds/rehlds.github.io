# Proyecto y licencia

ReGameDLL_CS lo mantiene la comunidad de ReHLDS. Reconstruye y amplía la GameDLL de servidor de Counter-Strike/Condition Zero para que administradores y desarrolladores de plugins dispongan de una implementación mantenida y que se puede inspeccionar.

## Enlaces del proyecto

- [Repositorio de código fuente](https://github.com/rehlds/ReGameDLL_CS)
- [Última versión estable](https://github.com/rehlds/ReGameDLL_CS/releases/latest)
- [Incidencias](https://github.com/rehlds/ReGameDLL_CS/issues)
- [Organización ReHLDS](https://github.com/rehlds)

## Licencia

El código fuente actual se distribuye bajo la licencia incluida en el repositorio. ReGameDLL_CS pasó a la licencia MIT en 2025; consulta el archivo [`LICENSE`](https://github.com/rehlds/ReGameDLL_CS/blob/master/LICENSE) vigente en el repositorio para conocer los términos autorizados antes de redistribuir código o binarios.

Valve, Counter-Strike, Half-Life y los nombres y materiales relacionados pertenecen a sus respectivos propietarios. ReGameDLL_CS no incluye todos los datos comerciales del juego necesarios para ejecutar un servidor.
