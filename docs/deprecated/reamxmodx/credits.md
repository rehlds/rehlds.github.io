# Credits

ReAMXModX is a fork of **AMX Mod X**, created and maintained by [AlliedModders](https://www.amxmodx.org/). All of the substantial work in this repository is theirs; the fork adds ReHLDS and ReGameDLL SDK glue on top of an August 2016 snapshot of the `1.8.3` development tree (`git5067`).

The Pawn abstract machine and compiler bundled with AMX Mod X are © ITB CompuPhase, 1997–2005.

:::warning Deprecated

The fork is **obsolete** — upstream AMX Mod X supports ReHLDS natively. Use [AMX Mod X](https://www.amxmodx.org/) instead.

:::

This fork does not accept new work. Contribute to [upstream AMX Mod X](https://github.com/alliedmodders/amxmodx), or — for reaching ReHLDS and ReGameDLL_CS internals from Pawn on a modern server — to [ReAPI](/docs/reapi).
