# Credits

ReHLDS is the result of reverse engineering the original HLDS (build 6152/6153) using the DWARF debug information embedded in the Linux build of HLDS (`engine_i486.so`). Along the way, the project's maintainers and contributors found and fixed a large number of defects and potential bugs in the original engine. It is maintained by the ReHLDS community as a non-commercial, open-source project.
