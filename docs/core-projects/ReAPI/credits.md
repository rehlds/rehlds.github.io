# Credits

ReAPI is an AMX Mod X module maintained by the ReHLDS community. It exposes [ReHLDS](/docs/rehlds) and [ReGameDLL_CS](/docs/regamedll-cs) internals to Pawn plugins through hook chains, member accessors, and capability-check natives, so plugin authors don't have to patch raw memory offsets themselves.

## How to help

Run ReAPI on your game server and report any problems you encounter through the [issue tracker](https://github.com/rehlds/ReAPI/issues), including your AMX Mod X, ReHLDS, and ReGameDLL_CS versions, a plugin list, and steps to reproduce. Pull requests are also welcome.
