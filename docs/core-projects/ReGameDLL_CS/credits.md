# Project and license

ReGameDLL_CS is maintained by the ReHLDS community. It reconstructs and extends the Counter-Strike/Condition Zero server-side GameDLL so server operators and plugin developers can use a maintained, inspectable implementation.

## Project links

- [Source repository](https://github.com/rehlds/ReGameDLL_CS)
- [Latest stable release](https://github.com/rehlds/ReGameDLL_CS/releases/latest)
- [Issue tracker](https://github.com/rehlds/ReGameDLL_CS/issues)
- [ReHLDS organization](https://github.com/rehlds)
