## How to help

Run ReUnion on your game server and report any problems through the [issue tracker](https://github.com/rehlds/ReUnion/issues), including your ReHLDS version, `reunion.cfg`, and console output with `-console +log on +mp_logecho 1`. Pull requests are also welcome.
