# Credits

ReSemiclip is a Metamod plugin originally written by s1lent and maintained since by the ReHLDS community, using [joaquimandrade's Semiclip module](https://github.com/joaquimandrade) as a reference implementation.

## How to help

Run ReSemiclip on your game server and report any problems through the [issue tracker](https://github.com/rehlds/ReSemiclip/issues), including your ReHLDS/ReGameDLL_CS versions and the relevant part of your `config.ini`. Pull requests are also welcome.
